# InkStory для Aidoku — версия 3

Исправлено получение настоящих глав и страниц читалки.

## Установка

Импортируйте `ru.inkstory-v3.aix` в Aidoku как обновление источника InkStory. Затем заново откройте тайтл в каталоге и обновите список глав. Старые записи «Комментарии», «Отзывы», «Обсуждения», «Медиа» из версии 1 не являются главами. При попытке открыть такую запись версия 3 просит обновить список.

## Изменения

Версия 3 исправляет кодировку вкладок «Популярное» и «Новинки». Названия в source.json сохранены как JSON Unicode escapes, чтобы их не повреждала перекодировка редактором. Добавлена проверка названий.


- Полный список глав берётся из встроенных данных TanStack, а не из ссылок меню.
- Проверяется принадлежность глав выбранному тайтлу; сохраняются номера глав, тома и переводчики.
- Страницы берутся только из массива pages запрошенной главы и сортируются по index.
- Обложки и аватары не используются в качестве страниц.
- Адреса изображений с маркерами x/s преобразуются в обычные адреса по fallback-алгоритму самой читалки InkStory. Это путь, который сайт использует без service worker.
- Удалён ошибочный перебор ?page=N.
- Старые ложные chapter keys отклоняются до сетевого запроса.
- В GitHub Actions добавлены проверки обработчика глав и страниц.

## Обновление GitHub

Замените содержимое корня репозитория файлами из ZIP, включая `.github`, `src/bootstrap.js`, `src/extract.js` и `tests`. Не создавайте дополнительную вложенную папку. После коммита результат сборки доступен в Actions → Build InkStory Aidoku Source → inkstory-aix.
Копия workflow для ручного редактирования: GITHUB_WORKFLOW.yml.txt.

## Локальная сборка

```sh
rustup target add wasm32-unknown-unknown
cargo install --git https://github.com/Aidoku/aidoku-rs --rev e1320b0a2e11afb59e4dee374883a2212d325699 --locked aidoku-cli
node --test tests/extract.test.cjs
bash build.sh
```

Результат: package.aix.

## Проверено

На сохранённых ответах публичного сайта: 144 записи глав Токийского Гуля, 46 страниц главы 1; 47 страниц проверенной главы Solo Leveling. Скачаны обычные JPEG/WebP по полученным адресам; страница Токийского Гуля проверена визуально. Десять тестов, компиляция WebAssembly и валидация .aix прошли успешно.

Проверка извлечения данных выполнялась в изолированном JavaScript-контексте Node с теми же bootstrap.js/extract.js, которые встроены в источник. Проверки непосредственно на iPhone здесь не было. Платные, закрытые и недоступные главы не обходятся; при отсутствии страниц выдаётся ошибка.
